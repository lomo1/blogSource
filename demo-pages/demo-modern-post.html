Hexo 博客升级到 8.1.2 版本

📅 2026-08-09 📁 技术 🏷️ Hexo, Node.js ⏱️ 8 分钟阅读

升级背景

我的 Hexo 博客一直运行在 6.1.0 版本，随着时间推移，许多新特性和安全补丁都无法享受。最近决定对整个博客系统进行一次全面升级，目标版本是当前最新的 8.1.2。

升级前的准备

在正式升级之前，我做了以下准备工作：

  • 创建了专门的升级开发分支 hexo-upgrade
  • 详细分析了所有依赖包的兼容性
  • 备份了现有的博客内容和配置文件
  • 检查了 Jacman 主题与新版本的兼容性

升级过程

升级过程比预想的顺利，主要步骤包括：

1. 升级 Hexo 核心

npm install hexo@^8.1.2 --save

Hexo 8.x 版本带来了许多性能优化和新特性，包括更快的生成速度、更好的插件系统等。

2. 升级插件

所有插件都升级到了与 Hexo 8 兼容的版本：

  • hexo-deployer-git: 3.0.0 → 4.0.0
  • hexo-generator-archive: 1.0.0 → 2.0.0
  • hexo-generator-category: 1.0.0 → 2.0.0
  • hexo-generator-index: 2.0.0 → 4.0.0
  • hexo-generator-tag: 1.0.1 → 2.0.0
  • hexo-renderer-ejs: 2.0.0 → 3.0.0
  • hexo-renderer-marked: 5.0.0 → 6.3.0
  • hexo-renderer-stylus: 2.1.0 → 3.0.1
  • hexo-server: 3.0.0 → 4.0.0

3. 测试验证

升级完成后，进行了全面的测试：

  • 本地生成测试：hexo generate - 成功生成 303 个文件
  • 本地预览测试：hexo server - 页面正常显示
  • 部署测试：hexo deploy - 顺利部署到 GitHub Pages

遇到的问题

整个升级过程非常顺利，没有遇到任何兼容性问题。这主要得益于：

  1. Jacman 主题使用的是标准的 Hexo API，没有使用废弃的特性
  2. 所有插件都有与 Hexo 8 兼容的版本
  3. 升级前做了充分的兼容性分析

升级收益

升级到 Hexo 8.1.2 后，获得了以下改进：

  • 性能提升：生成速度明显加快
  • 安全性：修复了旧版本中的安全漏洞
  • 新特性：支持更多的插件和功能扩展
  • 维护性：使用最新版本更容易获得社区支持

总结

这次 Hexo 升级非常成功，没有遇到任何问题。对于还在使用旧版本 Hexo 的朋友，建议尽早升级到最新版本，以享受更好的性能和更多的新特性。

下一步计划对 Jacman 主题进行现代化改造，引入暗色模式、响应式布局等现代设计元素。

💡 提示：升级前一定要做好备份，并在开发分支上进行测试，确认无误后再合并到主分支。
