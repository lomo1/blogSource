# Hexo 主题设计 Demo 页面

这个目录包含两个对比 demo 页面，展示 Jacman 主题的当前风格与现代化设计方案。

## 📁 文件说明

### 1. demo-current.html
**当前 Jacman 风格（2016-2017）**

展示 Jacman 主题的现有设计风格：
- ✅ 传统两栏布局
- ✅ 固定配色方案（蓝色主题）
- ✅ 基础响应式支持
- ✅ 简单的悬停效果
- ❌ 无暗色模式
- ❌ 无现代交互

**技术特点**：
- 纯 CSS（无 CSS Variables）
- 简单的 jQuery 风格交互
- 固定字号
- 传统盒模型布局

---

### 2. demo-modern.html
**现代化设计方案（2024-2026）**

展示经过现代化改造后的设计：
- ✅ CSS Variables 设计系统
- ✅ 暗色模式（可切换）
- ✅ 流式排版（响应式字号）
- ✅ 卡片化设计
- ✅ 微交互动画
- ✅ 阅读进度条
- ✅ 代码块复制功能
- ✅ 毛玻璃效果
- ✅ 平滑过渡动画

**技术特点**：
- CSS Variables（设计令牌）
- 原生 JavaScript（无依赖）
- clamp() 流式排版
- Grid 布局
- 现代化交互体验

## 💡 设计亮点

### 现代版本的关键改进

#### 1. 设计令牌系统
```css
:root {
  /* 完整的颜色系统 */
  --color-primary-500: hsl(195, 69%, 48%);
  
  /* 间距系统（8px 网格） */
  --space-4: 1rem;
  
  /* 流式排版 */
  --font-size-base: clamp(1rem, 0.9rem + 0.5vw, 1.125rem);
}
```

#### 2. 暗色模式
- 自动检测系统偏好
- 手动切换并保存到 localStorage
- 平滑过渡动画（0.3s）
- 优化的对比度

#### 3. 微交互
- 卡片悬停效果（提升 + 阴影加深）
- 导航下划线动画
- 按钮状态反馈
- 页面加载淡入动画

#### 4. 阅读进度条
- 固定在顶部
- 实时更新滚动进度
- 视觉反馈清晰

#### 5. 代码块增强
- 复制按钮（悬停显示）
- 复制成功反馈
- 语法高亮准备
- 圆角 + 边框
